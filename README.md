# Agent A｜V6.6微调版 V6.6.1

这是正式的股票决策辅助 Agent，支持A股、美股和港股。结果仅供学习与研究，不构成投资建议。

## 为什么回到V6.6

V6.7增加的ROIC、FCF、利润率趋势和估值历史分位，在A股、美股和港股的免费公开接口中不能保证每次都取得完整且可比的数据。因此V6.6.1不把这四项加入正式评分，恢复V6.6的91项可执行因子与规则。

## 本次只做了什么微调

- 修复“全市场认证名单为空时，把所有股票因子贡献清零”的逻辑问题。
- 当前状态观察分照常计算，可以区分偏强、中性和偏弱。
- 历史验证只决定这个状态能不能作为操作依据，不再把状态分清零。
- 单股历史验证未通过时，仓位上限仍为0。
- 单股验证通过但跨股票认证未完成时，方向可信度最高69，仓位最高3%。
- 风险问卷、股票风险分、持有期选择、基本面原有因子、资讯、卖出、加仓、会话和Supabase逻辑保持V6.6原样。

## 正式评分使用的基本面数据

V6.6.1只保留原有七项：ROE、净利率、净利润同比、营业收入同比、资产负债率、经营现金流／净利润、市盈率TTM。

对于某次无法取得的单项数据：

- 不估算；
- 不用行业平均数代填；
- 该项0分，不加分也不扣分；
- 可测基本面项少于2项时，整个基本面模块不参与方向分。

## 部署

1. 将本文件夹里的全部内容上传到Agent A的GitHub仓库根目录并覆盖旧文件。
2. Streamlit Main file path保持`app.py`。
3. 不需要重新运行SQL，不需要修改Secrets。
4. 不要把Agent B的文件上传到Agent A。

## 主要文件

- `app.py`：正式页面。
- `agent_core.py`：V6.6.1评分、风险、周期与仓位逻辑。
- `factor_analysis.py`：91项因子字典、贡献解释与历史验证。
- `完整因子字典_V6.6.1.csv`：可筛选的完整因子说明。

## Agent B

Agent B页面和“只使用T日及以前数据”的规则不改。由于独立部署的B内部保存了A的运行核心，A变为V6.6.1后，B也必须同步这个核心和版本校验值；否则B仍会按旧A推算。
