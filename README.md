# Agent A｜状态判断修正版 V6.7.1

这是面向正式用户的股票决策辅助页面。入口文件是`app.py`。

本文件夹只属于Agent A，不包含历史测试页面。

## V6.7.1修复内容

V6.7把“尚未完成跨股票认证”错误地当成“所有股票都没有判断证据”，导致趋势、动量和相对强弱贡献统一归零，所有股票都容易显示方向证据不足。

V6.7.1把两件事分开：

- 当前状态观察分：始终按固定因子和固定权重计算，显示偏强、中性或偏弱；
- 方向认证：只决定能否形成可操作方向、可信度和仓位，不再删除观察分。

若本股票自身历史验证未通过，Agent仍会给出状态结论，但仓位保持为0；若本股票自身验证通过但跨股票认证未通过，方向可信度受到限制，仓位上限不超过3%。

## V6.7加入的四项判断因子

| 因子 | 判断什么 | 分值范围 | 缺失时 |
| --- | --- | ---: | --- |
| ROIC | 公司使用债权和股权资本创造经营回报的效率 | -6至+6 | 不参与 |
| 自由现金流FCF | 经营现金流扣除资本开支后是否仍有剩余 | -6至+5 | 不参与 |
| 毛利率／营业利润率趋势 | 连续两期盈利能力改善还是恶化 | -5至+5 | 不参与 |
| 估值历史分位 | 当前估值相对公司自身历史偏高还是偏低 | -5至+4 | 不参与 |

四项因子会先进入“基本面辅助分”，再对中长期周期作有限修正，最终修正仍不超过正负4分；短期周期不使用这些基本面因子。

网页“因子解释与验证”中会逐项显示当前值、得分贡献、是否参与和原因。数据不足时不会估算或用0冒充真实值。

## 上传到现有Agent A

1. 解压安装包。
2. 打开`Agent_A_正式版_V6.7.1`文件夹。
3. 把文件夹里面的全部内容上传到正式Agent A的GitHub仓库根目录。
4. 同名文件选择覆盖。
5. Streamlit的Main file path仍然填写`app.py`。
6. 等待Streamlit自动重启。

本次不需要重新运行SQL，也不需要修改Streamlit Secrets。

不要把`Agent_B_历史测试版_V6.7.1`中的文件上传到正式A仓库。

## 本地运行

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 模型边界

- 结果只供学习和研究，不构成投资建议。
- 观察分不是上涨概率。
- 低估值不等于一定上涨，高ROIC也不等于短期股价一定上涨。
- 缺少可靠财务字段时，相应因子不参与评分。
- 当前方向认证仍采用保守闸门，不会为得到“买入”结论而放宽规则。
